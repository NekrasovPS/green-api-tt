Легковесный пользовательский интерфейс (Thin Client) для отправки и получения сообщений через шлюз [GREEN-API](https://green-api.com/). Проект разработан в рамках тестового задания на позицию Frontend-разработчика.

---

## ✅ Реализованный функционал

- **Отправка сообщений:** Интеграция с HTTP API GREEN-API (метод `sendMessage`).
- **Optimistic UI:** Мгновенное отображение отправленных сообщений в интерфейсе с автоматическим откатом (Rollback) и уведомлением пользователя в случае ошибки сети.
- **Получение сообщений:** Изолированный фоновый процесс (Long Polling) через метод `receiveNotification` с автоматической очисткой обработанных уведомлений из очереди сервера.
- **Синхронизация контактов:** Автоматический маппинг числовых Telegram ID (приходящих от сервера) с номерами телефонов из локальной книги контактов.
- **Управление состоянием:** Сессия (токены API), список контактов и история переписки сохраняются в `localStorage` с помощью Zustand Persist — данные не теряются при перезагрузке страницы.

---

## 🛠 Технологический стек

- **Core:** React 19, TypeScript
- **Build Tool:** Vite
- **State Management:** Zustand
- **Сетевые запросы:** Axios (настроен глобальный Interceptor для перехвата сетевых ошибок)
- **Стилизация:** SCSS / CSS Modules (изоляция стилей, БЭМ-подобный нейминг)
- **Архитектура:** Разделение на логические слои (API, Store, Components, Utils, Types) с соблюдением принципов инверсии зависимостей и единой ответственности (SOLID).

## 🚀 Инструкция по локальному запуску

1. Склонируйте репозиторий:

```bash
git clone <ссылка-на-ваш-репозиторий>
```

2. Перейдите в директорию проекта:

```bash
cd green-api
```

3. Установите зависимости:

```bash
npm install
```

4. Запустите проект в режиме локальной разработки:

```bash
npm run dev
```

5. Откройте в браузере указанную в консоли ссылку (по умолчанию `http://localhost:5173`).

---

## 💡 Как использовать приложение

1. На стартовом экране авторизации введите свои `idInstance` и `apiTokenInstance`. Эти данные можно получить в личном кабинете системы GREEN-API.
2. В левой панели интерфейса нажмите **"Добавить контакт"** и введите имя и номер телефона получателя (поддерживается любой формат ввода, цифры очищаются автоматически).
3. Выберите созданный контакт в списке слева и начните переписку.

> **Примечание:** Данное React-приложение выступает исключительно в роли UI-прослойки. Фактическая маршрутизация сообщений (в WhatsApp или Telegram) зависит от настроек используемого вами инстанса на стороне серверов GREEN-API.

## ⚠️ Известные ограничения (Антифрод и VPN)

**Блокировка VPN:**
Если на вашем устройстве включен VPN (особенно с IP-адресами публичных дата-центров), встроенная защита GREEN-API (WAF/Cloudflare) может принудительно разорвать соединение на уровне сети.

Приложение перехватывает данную ошибку (`ERR_NETWORK`) и выводит соответствующее предупреждение в интерфейсе. **Для корректной работы сервиса и успешной отправки запросов необходимо отключить VPN.**
