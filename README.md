## ✅ Реализованный функционал

- **Отправка сообщений:** Интеграция с HTTP API GREEN-API (метод `sendMessage`).
- **Optimistic UI:** Мгновенное отображение отправленных сообщений в интерфейсе с автоматическим откатом (Rollback) и предупреждением пользователя в случае сетевого сбоя.
- **Получение сообщений:** Изолированный фоновый процесс (Long Polling) через метод `receiveNotification` с обязательной очисткой обработанных уведомлений из очереди сервера (`deleteNotification`).
- **Синхронизация контактов:** Автоматический маппинг числовых Telegram ID, приходящих от сервера, с номерами телефонов из локальной книги контактов.
- **Управление сессией и изоляция данных:** Токены API, история переписки и список контактов сохраняются в `localStorage` с помощью Zustand Persist. Реализован полный логаут со сбросом стейта и очисткой хранилища во избежание коллизий между разными аккаунтами.

## 🛠 Технологический стек

- **Core:** React 19, TypeScript
- **Build Tool:** Vite
- **State Management:** Zustand (с мидлварей `persist`)
- **Сетевые запросы:** Axios (с глобальным `interceptor` для перехвата сетевых блокировок)
- **Стилизация:** SCSS / CSS Modules (изоляция стилей компонентов)
- **Архитектура:** Модульная структура с разделением ответственности (API, Store, Components, Utils, Types) и следованием принципам SOLID.

## 🚀 Инструкция по локальному запуску

1. Склонируйте репозиторий:
```bash
git clone https://github.com/NekrasovPS/green-api-tt.git
```

2. Перейдите в директорию проекта:
```bash
cd green-api
```

3. Установите зависимости:
```bash
npm install
```

4. Запустите проект в режиме локальной разработки:
```bash
npm run dev
```

5. Откройте в браузере локальный адрес (по умолчанию `http://localhost:5173`).

## 💡 Как использовать приложение

1. На стартовом экране авторизации введите свои `idInstance` и `apiTokenInstance` из личного кабинета GREEN-API.
2. В сайдбаре нажмите **"Добавить контакт"**, укажите имя и номер телефона (форматирование и валидация происходят автоматически).
3. Выберите появившийся контакт в списке и начните переписку.
4. Для завершения сессии и полной очистки локальных данных нажмите кнопку **"Выйти"** в шапке панели контактов.

> **Примечание:** Данное приложение выступает UI-оболочкой. Фактическая маршрутизация сообщений (в WhatsApp или Telegram) определяется настройками вашего инстанса в консоли GREEN-API.

## ⚠️ Известные ограничения (Антифрод и VPN)

**Блокировка VPN:**
Если на устройстве активен VPN (особенно с IP-адресами публичных дата-центров), защитные WAF-экраны сервиса GREEN-API могут принудительно прерывать запросы (`ERR_NETWORK` / `403 Forbidden`). 

Приложение перехватывает сетевой обрыв и выводит предупреждение. **Для корректного обмена сообщениями с сервером отключите VPN.**
